网页翻译 · 界面设计样稿

约束：不改动 Codex 扩展现有的任何界面。翻译功能全部由新增元素承载—— 网页内的轻量浮层，加上一个独立的设置页。配色、圆角、按钮形态沿用扩展现有的深色视觉语言， 使新增部分看起来像本来就属于它。

01网页内的元素

四块，都是按需出现、不占常驻空间。没有任何常驻按钮，也没有快捷键，唯一入口是右键菜单。

① 划词气泡选中文字后出现
https://example.com/article

Machine learning models need to be trained on large amounts of data before they generalize well. This is especially true for tasks with long-tail distributions.

The training loop ...

译为 简体中文
对于长尾分布的任务来说尤其如此，模型必须在大量数据上训练才能获得良好的泛化能力。

齿轮进设置页的「语言与显示」；复制只写剪贴板，替换原文会记下原句以便还原。

② 气泡的另外两个状态翻译中 / 失败
https://example.com/article
正在翻译…
翻译失败本地模型未响应
请确认 Ollama 正在运行，或到设置页检查模型配置。

失败态必须给出下一步动作，不能只甩一句报错。

③ 整页翻译 · 双语对照进度胶囊 + 边翻边出
https://example.com/article

Machine learning models need to be trained on large amounts of data.

机器学习模型需要在大量数据上训练。

This is especially true for long-tail tasks.

正在翻译 34 / 128 段

译文用略低的对比度和轻微色偏和原文区分；进度胶囊只占底部一条，不遮挡内容。

④ 视频字幕翻译双语字幕条，跟随播放进度
https://example.com/watch

只翻译正在播放的字幕轨，不碰页面其他内容；原字幕已是双语时只补缺失的一侧。
