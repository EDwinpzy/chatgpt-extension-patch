# 网页翻译助手

这是从当前扩展中独立出来的 Chrome / Edge Manifest V3 插件，包含划词翻译、整页自动翻译、视频字幕翻译和模型、语言、术语表、站点设置。不包含 Codex 侧边栏或书签功能。

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页并启用“开发者模式”。
2. 选择“加载已解压的扩展程序”。
3. 选择本目录 `translation-extension`。
4. 点击工具栏上的插件图标打开设置，配置可用的翻译模型。

也可以在网页中右键使用“翻译选中文字”“翻译整页”或“还原本页原文”。新标签页、浏览器内置页面和 `chatgpt.com` 不注入翻译脚本。
